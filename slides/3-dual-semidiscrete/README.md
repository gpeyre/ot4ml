# Duality, W1, and Semi-discrete OT

This is the third Quarto + Reveal.js deck for OT4ML. It follows the reference deck `slides/references/3-DualSemiDiscrete.pdf` while replacing dense raster slides by editable equations, semantic mathematical boxes, algorithmic summaries, book figures, and one lightweight interactive Laguerre-cell panel.

## Render

From this directory:

```bash
quarto render index.qmd
```

The output is `index.html`.

## Structure

The deck is organized into five roadmap parts:

1. Duality
2. W1 and IPMs
3. Semi-discrete OT
4. Quantization
5. Learning links

It currently contains 45 slides, 43 local PNG assets, three algorithm boxes for dual closure, semi-discrete descent, and Lloyd iterations, plus an interactive Laguerre-cell panel.

Shared formatting conventions are documented in `../formating.md`; the Reveal theme is `../_common/ot4ml-reveal.scss`.
