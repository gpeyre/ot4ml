\chapter{Notation Table}
\label{app-notation-table}

This appendix collects the main notation used throughout the book. The last
column points to the first section, equation, definition, proposition or theorem
where the notation is defined or first used in a mathematically meaningful way.
The global convention is that $\alpha,\beta$ denote the main source and target
measures. A single generic measure is also denoted by $\alpha$;
auxiliary measures use contextual letters such as $\nu,\gamma$ or $\eta$.
